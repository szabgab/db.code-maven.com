Want to know how the sausage is made in Postgres? This meetup will be a hands on walkthrough of how the development of the open source PostgreSQL project works.

We'll show you how to get a development version of Postgres running and wow its version 20! We'll also show you how updates to the code base are suggested, discussed, reviewed, and committed. If you're curious about being a Postgres hacker or just want a deeper look into the project, this will be a fun meetup.

We'll also take a peek at the patch review process in case anyone in the group is interested in participating in the actual open source process. You will need a community email here (https://www.postgresql.org/).

## Bios

[David Christensen](https://www.linkedin.com/in/david-christensen-66bb8920/) has been a PostgreSQL hacker since 2010 (\conninfo) and he has a new GROUP BY ALL feature coming soon hopefully in Postgres 20.

[Elizabeth Christensen](https://www.linkedin.com/in/elizabeth-garrett-christensen/) is a PostgreSQL contributor - mostly doing advocacy work but does have a first patch in!
